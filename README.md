FoodLens: AI-Powered Food Donation & Distribution Platform 🍲🤖
            FoodLens is a hackathon project developed during the Smart India Hackathon 2025. 
            It leverages Python, Streamlit, SQLite, and AI-based food image recognition to efficiently match excess food from donors with NGOs, 
  aiming to reduce food wastage and improve community access to meals 🌱💡.

Features include:
         AI-powered food recognition for automatic categorization 🧠
         Donation tracking and NGO matching system 📊
         Easy-to-use web interface built with Streamlit 🌐
